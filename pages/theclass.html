01 / CHANNEL

혜택과 전문성의 동시 탐색

아울렛과 온라인몰 이용이 두드러지지만, 조사기관은 브랜드 신뢰와 제품 전문성도 구매 결정에 중요하다고 해석했습니다.

02 / SEGMENT

고객군별 채널 차이

여성은 백화점, 젊은 남성은 브랜드 공식몰과 골프 전문 채널의 이용 비율이 상대적으로 높았습니다.

03 / COMPETITOR SIGNAL

필드 밖으로 확장

지포어는 도심 캠페인, 더카트는 스포츠·웰니스 카테고리와 경험을 제안합니다. 이는 브랜드 전략의 사례입니다.

CONCLUSION

고객별 브랜드 탐색·상품 비교·혜택 확인·구매 후 관리를 끊김 없이 연결하는 쇼핑 경험이 필요합니다.

경쟁사 근거: 지포어 2026 캠페인 · 더카트 플랫폼 개편 · 더카트 2026 웰니스 프로그램. 이 방향은 2026년 자료에서 도출한 기획 인사이트이며 2021년 당시의 판단과 구분합니다.

03 / SERVICE PLANNING

더클래스가 다룬 쇼핑의 전 과정.

브랜드·카테고리·검색을 병렬 탐색 경로로 설계하고, 찜·구매·배송·리뷰를 하나의 쇼핑 여정으로 연결했습니다.

08 / POLICY DEFINITION

정책 정의서

회원 상태, 결제 결과, 주문 진행 상태에 따라 화면과 가능한 행동이 달라지도록 정책을 정의했습니다. 확정되지 않은 운영 수치는 결정 항목으로 남겼습니다.

P-01

회원 가입·중복 계정

기본 규칙

가입을 시작하면 본인 인증 결과와 기존 회원 여부를 확인합니다.

예외·확인 사항

기존 회원이면 가입 진행 대신 계정 확인 화면으로 연결합니다. 결과가 없으면 가입을 계속합니다.

관련 화면: 가입 본인인증 / 기존회원 / 결과없음
P-02

로그인·계정 연동

기본 규칙

일반 계정과 소셜 계정 진입을 제공합니다. 다른 가입 방식으로 이미 연결된 계정은 연동 안내를 표시합니다.

예외·확인 사항

인증 실패와 비밀번호 조건 미충족은 해당 입력 화면에서 해결하도록 합니다.

관련 화면: 로그인 / 일반가입 후 소셜 / 소셜가입 후 다른 소셜 / 비밀번호 재설정
P-03

비회원 제한

기본 규칙

찜, 브랜드 즐겨찾기, 상품 문의 등 계정 기반 기능을 선택하면 로그인을 안내합니다.

예외·확인 사항

로그인 후 이전 상품·브랜드 화면으로 복귀할지는 별도 정책 결정 항목입니다.

관련 화면: 비회원 찜 / 즐겨찾기 / 상품문의
P-04

주문 금액·포인트

기본 규칙

주문 화면에서 상품 금액, 배송 정보, 포인트 사용, 결제수단을 확인합니다. 수량이나 포인트가 바뀌면 표시 금액을 다시 계산합니다.

예외·확인 사항

포인트 사용 한도와 배송비 계산식은 운영 정책 확정 후 적용할 항목입니다.

관련 화면: 장바구니 수량변동 / 포인트사용 / 결제수단
P-05

결제 결과

기본 규칙

결제 성공 시 주문완료로, 실패 시 결제오류 상태로 분기합니다. 무통장 주문은 카드·휴대폰 결제와 다른 완료 정보를 표시합니다.

예외·확인 사항

결제 실패 후 주문 생성 여부와 재시도 방식은 개발 연동 전 확정해야 합니다.

관련 화면: 주문완료 카드·휴대폰 / 무통장 / 결제오류
P-06

주문 후 처리

기본 규칙

주문 상태에 따라 배송조회, 배송지 변경, 구매확정, 취소, 교환, 반품 행동을 구분해 노출합니다.

예외·확인 사항

취소·교환·반품 신청의 성공과 오류 상태를 각각 제공합니다.

관련 화면: 주문내역 / 교환·반품 신청 / 신청완료·신청오류
P-07

포인트 내역

기본 규칙

보유·사용 내역과 소멸 예정 포인트를 별도 상태로 조회합니다.

예외·확인 사항

적립률, 사용 한도, 소멸 기간은 운영 정책 확정이 필요한 항목입니다.

관련 화면: 포인트 메인 / 내역없음 / 소멸예정

  • Order — orderId, items, shipping, payment, status, totals
  • Review / Inquiry — author, productId, content, status
  • PointTransaction — type, amount, balance, expiryAt
